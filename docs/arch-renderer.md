# `src/renderer` — React UI (sandboxed web process)

Everything the user sees and interacts with. It has no Node or filesystem access. It reaches the main process only through `window.api` (see `arch-preload.md`) and plays media only through `media://<id>` URLs.

## Entry points

- **`index.html`** — page shell and CSP (`default-src 'self'`; `img-src`/`media-src` allow `data:` and `media:`). App title is "Reelszer".
- **`src/main.tsx`** — mounts `<App />` in `StrictMode` and loads `styles.css`.
- **`src/App.tsx`** — root component and owner of all app-level state:
  - Sidebar navigation between the `editor`, `downloader` and `library` pages. This is a `useState`, with no router.
  - `sources`, `flashImages` (+ `flashNotice`, `flashRepeats`), `presets`, `music`, `exportProgress`, `downloads`, and the editor settings from `useEditorSettings()`. State lives here so it survives page switches.
  - IPC orchestration: imports videos, music and flash images; loads the library on mount and auto-saves `{ presets, music }` on change; builds the `ExportRequest` and calls `export.run` and `export.cancel`; subscribes to `export.onProgress`.
  - Sidebar navigation between the `editor`, `downloader` and `library` pages. This is a `useState`, with no router. The sidebar has a brand header (`BrandMark` from `components/ui.tsx` plus "Reelszer") and collapses to icons only. The `collapsed` flag adds `app--collapsed` to the root, animates the grid column width, and is saved in `localStorage` (`sidebar-collapsed`). Collapsed items show CSS-only tooltips from `data-tooltip`.
  - `sources`, `photoFolder`, `presets`, `music`, `exportProgress`, `downloads`, and the editor settings from `useEditorSettings()`. State lives here so it survives page switches.
  - IPC orchestration: imports videos, music and the photo folder; loads the library on mount and auto-saves `{ presets, music }` on change; builds the `ExportRequest` and calls `export.run` and `export.cancel`; subscribes to `export.onProgress`.
  - Session: on mount `session.load()` restores `sources`, `flashImages`, `selectedFlashImageIds` (as `selectedFlashIds`), `flashRepeats` and the editor settings (`actions.hydrate`, merged over `INITIAL_SETTINGS`). After that, a 400 ms debounced effect saves them on every change. When an export finishes (`kind: 'done'`), the sources that exported are removed (`removeSources`, which also drops their `sourceSettings`); failed ones (`ExportFailure.sourceId`) stay. Flash images, music and presets are kept. Cancelled or errored runs keep every source.
  - Downloads: loads `downloads.list()` and the folder on mount, and upserts items from `downloads.onUpdate`. Main owns the history; `downloads.start` doesn't return items, they arrive as update events. `onRemoveMany` calls `downloads.removeMany` and drops the items locally only if the user confirmed.

## Structure

- **`features/editor/`** — the main screen. `EditorPage` lays out three columns and is mostly props-driven.
  - `MediaColumn` — source list, flash images, music. The Source videos panel has a "Remove all" button (shown when there are sources) that needs a second click within 4s to confirm; it calls `removeSources` with every id, so the files stay on disk. Flash images are a pool: "Add images" appends up to `MAX_POOL_IMAGES` (100) in total (duplicates skipped, extras over the cap dropped with a notice, new images start unselected). Only one image can be selected: clicking a thumbnail makes it the single entry in `selectedFlashIds` (accent outline plus check badge), clicking the selected one clears it. Only selected images go into `flashImagePaths` and the missing-file check. Removing an image only drops it from the app and deselects it. A "Flashes per video" number field below the grid sets `flashRepeats`.
  - `PreviewColumn` — live CSS preview of the active source.
  - `SettingsColumn` — per-source text/caption, video and audio controls, and export quality.
  - `useEditorSettings.ts` — reducer holding `EditorSettings`. Settings are stored per source in `sourceSettings[sourceId]`. It exposes `EditorApi`. With `syncText` on ("Same caption style and position on all videos"), `getSourceSettings` returns `sharedText` as every source's `text`, and `patchText` edits `sharedText` instead. The preview, the settings panel and the export all follow from that. Turning the option on copies the active video's style into `sharedText`. Turning it off writes `sharedText` back into every source. `syncCaption` ("Same caption text on all videos", in the Caption presets panel) works the same way for `captionPresetId` via `sharedCaptionPresetId` and `setCaptionPreset`. The two options are independent.
  - `config.ts` — `VIDEO_CONTROLS` (range, step, neutral value, randomize range, optional `display` scale), defaults, `fontStyle(id)` (CSS family/weight from `src/shared/fonts.ts`), swatches and quality options. Values are **in FFmpeg units**, and the export uses them unchanged.
  - Each control has a `group` (`transform`, `color`). `SettingsColumn` shows the groups under subheadings, and the "Flip horizontally" checkbox (`flip`, the only boolean in `VideoProps`, set via `setVideoFlip`) sits under Transform. Randomize flips on a coin toss.
  - Temperature and vignette have `display: 0–100`. Brightness has `display: -100–100`. `toDisplay`/`fromDisplay` map linearly between that scale and the FFmpeg range in `SettingsColumn`, so state still holds FFmpeg values. On the temperature slider, 0 = 5100K (warm) and 100 = neutral 6500K.
  - `previewMath.ts` — converts FFmpeg units to CSS-preview values: an `eq` `feColorMatrix`, a temperature `feColorMatrix`, the vignette gradient, and perspective. This is the only place unit conversion for the preview happens.
  - `PreviewColumn` applies eq → temperature as one inline SVG filter on the `<video>`, in sRGB and in FFmpeg's order. Flip is `scaleX(-1)` in the transform, speed is `playbackRate`, and vignette is a gradient overlay on top.
  - `PreviewColumn` plays the selected music through a hidden looping `<audio>` synced to the video's play/pause. Selected music mutes the video; with no music the video is unmuted only if "Keep original audio" is on (same rule as export).
  - `*old.ts(x)` (`configold`, `PreviewColumnold`, `SettingsColumnold`) — dead earlier versions that nothing imports.
- **`features/downloader/DownloaderPage.tsx`** — TikTok link input (single or batch), a toolbar (output folder and Change), and the download history with progress, error text, and cancel, retry, show and remove actions. Every row and batch header has a checkbox, and there are no per-row trash buttons: deleting is one flow for one video or many. `History` keeps the selected ids. The panel toolbar has a single danger **Delete** button, disabled with 0 selected and labelled "Delete N video(s)" otherwise, which calls `onRemoveMany` with only the visible selected ids (a ticked batch counts all its links). A slim bar above the list has select-all, the count and Clear. The panel ends with a red, bottom-pinned note that deleting permanently deletes the video from the device. `groupHistory` folds batch items into one collapsible `BatchGroup` card per `batchId` (falling back to `createdAt` for older items). Groups start collapsed, and the card's aggregate progress and group actions loop over the per-item callbacks. It is props-driven, and `App` wires it to `window.api.downloads`.
- **`features/library/LibraryPage.tsx`** — read-only grid of the imported videos with totals.
- **`components/TitleBar.tsx`**: the 32px draggable window title bar at the top of `.shell` (above the sidebar + main grid). The native min/max/close buttons are drawn over its right side by Electron's `titleBarOverlay`; interactive children must be `-webkit-app-region: no-drag`.
- **`components/Navbar.tsx`**: `Navbar({ title, description })`, the top bar each page renders above its `.page` grid (inside a fragment).
- **`components/ui.tsx`** — shared presentational primitives: `Icon` (inline SVG paths), `Button`, `IconButton`, `Panel`, `EmptyState`, `Thumb`, `Slider`, `Segmented`, `RadioList`, `cx`.
- **`lib/`** — pure helpers. `format.ts` formats bytes, duration, resolution, relative time and plurals. `links.ts` validates and parses TikTok URLs.
- **`types.ts`** — re-exports the shared types from `src/shared/types.ts` (including `DownloadItem`, `DownloadStatus` and `DownloadMode`) and adds the renderer-only `EditorSettings`.
- **`styles.css`** — the active stylesheet. Colors are `:root` tokens following 60-30-10: black surfaces (`--bg`, `--surface` for cards, `--chrome` for the navbar and sidebar), purple `--secondary`/`--surface-3`/borders, and a cyan `--accent`. `assets/` holds `base.css`, `main.css` and the SVGs from the electron-vite template.
- **`env.d.ts`** — Vite client type references.

## Rules and gotchas

- The renderer never sees raw file paths for playback. `SourceVideo.previewUrl` is a `media://` URL minted by main.
- **Units convention:** config and export share FFmpeg units, and only `previewMath.ts` converts for CSS. Color constants that both sides depend on (`TEMPERATURE_KELVIN`, `TEMPERATURE_MIX`, `VIGNETTE_MAX_ANGLE`) live in `src/shared/colorConstants.ts`, which both main and renderer import.
- Per-source settings are keyed by source id. `App` reads them with `editor.getSourceSettings(id)` when it builds the export request.
- Open problem: the preview does not match the exported output (see `issues.txt`).
- Import style is mixed: `@renderer/types` alias, relative paths, and one `src/shared/types` import in `App.tsx`. The formatting also varies (semicolons in `lib/`, `main.tsx` and the downloader and library pages; none in `App.tsx` and the editor), so prefer the Prettier style when you touch a file.

- **Fonts:** `src/shared/fonts.ts` lists the caption fonts. `src/renderer/src/fonts.ts` registers the `resources/fonts/*.ttf` files via `FontFace` at startup, and the export uses the same files through `fontfile=`, so preview and output match. The Font panel is a grid of `role=radio` cards.
- **Caption position:** the caption can be dragged in `PreviewColumn` (pointer events on the text, clamped inside the frame), which sets `TextStyle.position` (`{ x, y }`, the box center as 0–1 fractions of the frame). When it's set, it overrides `vAlign`/`hAlign`. Choosing an alignment, or Reset in the "Text position" panel, sets it back to `null`. `export.ts` (`captionXY`) applies the same center with a clamp in `drawtext`.
- **Caption case:** the Font panel's "Case" control sets `TextStyle.textCase` (`none`/`upper`/`lower`). `applyTextCase` (in `src/shared/fonts.ts`) transforms the caption text in both `PreviewColumn` and `export.ts`.
